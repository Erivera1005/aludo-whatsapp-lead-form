# ALUDO WhatsApp Lead Form

Quiero crear una web tipo formulario para ALUDO, con muchas animaciones pero muy optimizada en velocidad de carga ya que es para una campaña de clientes potenciales en meta ads, esta tendra como colores principales el #000637, blanco y escala de grises claros. esta web funcionara unicamente como filtro del lead haciendole 2 preguntas y luego dirigiendolo a whatsapp, la primera pregunta es ¿Como se llama tu peludito? y la segunda es con base a a la primera respuesta: ¿Que raza es (NOMBRE)? y por ultimo una pantalla de carga que diga Ahora escribenos por whatsapp para ver como (NOMBRE9 podria habalr gracias al collar de ALUDO. haz la web optmizada para carga rapida despues del clikc en una publicidad sin perder animaciones y muy optimizada para celulares
